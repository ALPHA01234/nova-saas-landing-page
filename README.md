# NOVA — SaaS Landing Page Concept

A responsive, dark-themed landing page for a fictional productivity workspace called NOVA. This is a front-end portfolio project designed to demonstrate layout, visual hierarchy, responsive styling, and lightweight JavaScript interactions.

## Preview

After enabling GitHub Pages, the expected URL is:

https://alpha01234.github.io/nova-saas-landing-page/

## Built with

- HTML5
- CSS3 (Grid, Flexbox, responsive media queries, custom properties)
- Vanilla JavaScript
- Google Fonts: DM Sans and Space Grotesk

## Sections

- Announcement bar and responsive navigation
- Hero with an illustrative workspace mockup
- Brand-style logo strip
- Feature cards and workflow explanation
- Sample pricing tiers
- Call-to-action and FAQ
- Footer with dynamic copyright year

## Run locally

Open `index.html` in a browser. No build tools or package installation are required.

## Important demo notes

NOVA is a fictional product concept, not a live service. The logos, workspace interface, feature descriptions, and prices are illustrative. Sign-up, login, and pricing buttons are demo navigation only. The contact button uses the placeholder address `hello@example.com`; replace it with a real, authorized contact address before adapting the page for a real business.

## GitHub Pages

In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose the `main` branch and `/(root)` folder, then save. Wait for the deployment to finish before sharing the preview URL.
